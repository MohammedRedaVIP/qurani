# قرآني — تطبيق شخصي للحفظ والتلاوة

تطبيق ويب (PWA) بيشتغل من المتصفح ويتثبّت على شاشة الأندرويد الرئيسية.

## إيه اللي فيه
- نص عثماني كامل (114 سورة، 6236 آية) مبني جوه الملف — القراءة شغالة بدون نت.
- وضع **قراءة**: النص كامل، اضغط أي آية تسمعها.
- وضع **استماع**: تشغيل متتابع للآيات مع تظليل الآية الحالية، تكرار الآية، وتغيير السرعة.
- وضع **حفظ**: الكلمات مخفية — تضغط الكلمة تكشفها، والتطبيق يعدّ لك كام كلمة "استرقتها".
- تعليم الآيات المحفوظة + شريط تقدم لكل سورة (بيتحفظ على الجهاز).
- تسجيل صوتك لكل آية وحفظه على الجهاز وسماعه بعدين.

## الرفع على GitHub Pages
1. اعمل ريبو جديد (مثلاً `qurani`).
2. ارفع كل الملفات اللي جوه الفولدر ده في الجذر.
3. Settings → Pages → Source: Deploy from a branch → `main` / `/ (root)`.
4. افتح الرابط من موبايلك، وبعدين من قائمة كروم: "إضافة إلى الشاشة الرئيسية".

## مصادر
- النص العثماني: مجموعة بيانات مفتوحة (quranjson).
- التلاوات: everyayah.com (لكل آية ملف mp3).
- الخط: Amiri Quran من Google Fonts.

## اللي لسه ناقص (المرحلة الجاية)
- تظليل كلمة بكلمة وقت التلاوة (محتاج توقيتات QUL).
- كشف الأخطاء بالتعرّف الصوتي (ASR) — محتاج محرك على اللابتوب أو موديل أونلاين.
